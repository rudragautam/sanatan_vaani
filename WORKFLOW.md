# Bhagwan Vichaar — Project

## Design rule
`Bhagwan_Vichaar.html` is the exact HTML supplied by you.
**Do not change the design, CSS, responsive behavior, layout, animation, or aspect ratio.**

## Workflow
Topic/Deity → devotional thought JSON → background image → supplied HTML design → voice/music → final video.

The content file is `content/episodes.json`. It is kept separate so future automation
can generate new episodes without redesigning the HTML.

For paraphrases/original devotional copy, use `भावार्थ` or `विचार`; do not present an
invented line as a verbatim scripture quotation.
